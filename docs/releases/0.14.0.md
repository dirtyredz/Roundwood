# Roundwood 0.14.0 (Forge 1.20.1) — in development

- Includes the 0.13.4 door fix: clicking an open round door's projected free edge
  closes its own door through server-validated reach, obstruction and permission
  checks. Collision and swing geometry are unchanged. Both ends need the update.
- Modular arch pieces are being implemented in staged batches. Their approved
  geometry is three semicircular tops (height x width 1x1, 1x2, 2x3) and a mirrored
  keyhole shoulder, with existing archways retained for compatibility.

Rendering, attachments, recipes and showcase notes will be completed with those
implementation batches. This intermediate branch is not a finished feature release.
