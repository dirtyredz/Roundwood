# Roundwood 0.13.3 (Forge 1.20.1) — prerelease

Covers everything since the last pushed state (0.13.0 Cross Beams onward).

## New
- **Cross Beams (0.13.0):** whole-pane cross beams fitted onto any window profile, with their own wood/paint/masonry look; old crossed windows convert losslessly.
- **Archway corners filled (0.13.1+):** archways fill their corners while keeping full walking clearance (players, villagers, zombies).
- New mod and launcher logo.

## Fixed
- **Archways now show plank textures (0.13.3):** archways were drawing the stripped-log trim texture, so planks looked smeared and the grain ran sideways inside the opening. Every face of an archway now tiles the real plank (or masonry) texture, lined up with the world grid like a vanilla planks block.
- Owner feedback (0.13.1): showcase pieces spaced apart with readable signs and a full materials wall; no stray glass pane where windows meet; archway collision tightened to the lower jambs.
- EMI/JEI list each item once (one oak default per item).

## Under the hood
- Shared assembly, placement, appearance and client-model plumbing consolidated (no behaviour change).
- Package dependency cycles removed or documented; GameTests run on a guarded flat world.
