# Roundwood 0.13.4 (Forge 1.20.1) — prerelease

- Fixed the open round door's free edge highlighting correctly but refusing a click to close it.
  The projected leaf now routes use to its own door while preserving the actual aimed point.
- Guarded both door designs, both hinges, all four facings and closed-leaf use. Collision and
  swing geometry are unchanged; the projection still occupies no additional blocks.
- Projected clicks use a server-validated request with reach, obstruction, assembly and permission
  checks before the normal interaction router. Both client and server need this version.

Owner trial: close round and arched doors from their free edges from both sides, then reopen them;
repeat with opposite hinges and facings, camouflage and fitted trims, and on a second client.
