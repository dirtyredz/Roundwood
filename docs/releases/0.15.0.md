# Roundwood 0.15.0 (Forge 1.20.1) - trial

- Keyhole shoulders target all four block edges through four aimed-face wedges. Preview
  and placement share the classifier; existing facing/side states remain valid.
- Round 2x2 doors target front, middle or back depths. Hinge choice, collision, animated
  outlines, camouflage, casings and projected free-edge use follow the selected depth.
  Old saved states default to their historical front position.
- Added the Double Arched Door: one 3x3 assembly, two outer-hinged leaves moving together,
  square bottom and a crown matching the 2x3 arch above a one-block base. Place the arch
  flush against it in the adjacent depth layer. Both leaves retain full two-sided boards,
  brass straps and knobs. It supports the same appearance, trim, redstone and loot paths.
- Added recipe (PNP / PPP / PNP: planks and gold nuggets), language, generated models,
  tags, JEI/EMI/creative enumeration and a showcase sample. There are 24 advertised items.

- Fixed framed-door texture bleed: casing contact quads shared the panel planes and jamb
  edges shared hinge-strap planes. Door and modular arch casings now separate their render
  surfaces by 1/256 pixel along each normal; targets, collision and saved depths stay intact.
  A cheap model-surface guard checks all door designs, depths, both hinges/faces and adjacent arches.
- Added Tall Double Arched Door (3x4), using the same parameterized paired-door adapter.
  The existing 2x3 arch crown starts at y+2 instead of y+1; the lower opening gains one straight row.
  It includes all three depths, paint, trims, redstone, styled drops, models, lang, viewer entries
  and a showcase sample. Recipe: PPP / NDN / PPP (D = Double Arched Door).

Owner checks: aim at all four shoulder edges on floors and walls; compare overlays to
placement. Try round doors at each depth, both hinges, and close them from the free edge.
Place both double doors against a 2x3 arch, open both leaves, and check both faces, painted
looks, casing/camouflage, redstone, break/drop, save/reload and a second client. Check
both recipes and icons in JEI/EMI and the showcase. No visible client was used by the agent.
