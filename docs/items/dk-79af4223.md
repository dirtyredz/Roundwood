# Intermittent frame integrity GameTest under server lag


TrimLifecycleGameTests.aLoneLowerQuarterIsRemovedByTheIntegrityTick failed once on ANU (job Roundwood-worktree-agent-aef147c50-20261022-060627-ed0, sha c1510f4): "frame quarter left at ... round_trim[part=lower_left]" after its 3-tick wait. It passed on the runs before and after (jobs ...-055903-cc2 and ...-061049-929), with no frame code changed. That run logged heavy server lag ("Can't keep up"). It is likely a timing flake: the test checks at a fixed 3-tick delay while the integrity check is a scheduled tick.

Direction: wait with succeedWhen or a longer bounded wait instead of a fixed delay; check the same pattern in the archway and door lone-part tests.

## Resolution (2026-10-24)

Root cause: the GameTest world was never flat. ForgeGradle's GameTest server generated normal terrain, so plots sat in caves with falling blocks, fluids and cave mobs. Fixed in `26b249c` (shared `gradle/gametest-world.gradle`: flat, no structures, no spawning; guard `environment/TestWorldGameTests`). A separate villager-passage fixture flake was fixed in `0a77f98` (dk-dae6be18).

Evidence: full `test,runGameTestServer` on ANU, 347/347 passing on three consecutive runs at `9e87c1f` (2026-10-24 12:36, 12:38 and 12:40), plus 347/347 at `26b249c` (two runs) and at `86dabc2`. The only failure seen after the flat-world fix was the villager fixture, now fixed.
